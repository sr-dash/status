How this page works

Every %%EVERY_TEXT%% a GitHub Actions workflow checks each repository: that its site answers, its latest GitHub Pages deployment, open pull requests, every workflow's latest run (and whether a scheduled one is overdue), and how fresh each data feed is. The page is rebuilt from the result, so what you read here is the last check; it has %%N_RUNS%% checks of history.

A failure, or a warning that lasts three checks, opens an alert issue that emails the owner, and the issue closes itself when all is clear. The page is a reusable block: copy the repository, list your own repositories in status.config.yml, and turn on GitHub Pages.
